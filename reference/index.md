# Package index

## All functions

- [`analyse_bayes()`](https://adrianwurm.github.io/adaptsurv/reference/analyse_bayes.md)
  : Bayesian analysis of a data cut
- [`analyse_fixed()`](https://adrianwurm.github.io/adaptsurv/reference/analyse_fixed.md)
  : Analyse a data cut with the log-rank test and a Cox model
- [`bayes_probs()`](https://adrianwurm.github.io/adaptsurv/reference/bayes_probs.md)
  : Posterior probabilities P(HR \< 1 \| data) at each analysis
- [`calibrate_bayes()`](https://adrianwurm.github.io/adaptsurv/reference/calibrate_bayes.md)
  : Calibrate the efficacy threshold to a one-sided type I error
- [`cut_at_events()`](https://adrianwurm.github.io/adaptsurv/reference/cut_at_events.md)
  : Cut trial data at the calendar time of the k-th observed event
- [`oc_results`](https://adrianwurm.github.io/adaptsurv/reference/oc_results.md)
  : Operating characteristics of both designs (precomputed)
- [`operating_characteristics()`](https://adrianwurm.github.io/adaptsurv/reference/operating_characteristics.md)
  : Operating characteristics of the fixed and the Bayesian adaptive
  design
- [`posterior_gamma()`](https://adrianwurm.github.io/adaptsurv/reference/posterior_gamma.md)
  : Gamma posterior parameters of the exponential hazard rate per arm
- [`rpwexp()`](https://adrianwurm.github.io/adaptsurv/reference/rpwexp.md)
  : Simulate piecewise exponential survival times
- [`run_bayes_adaptive()`](https://adrianwurm.github.io/adaptsurv/reference/run_bayes_adaptive.md)
  : Run the Bayesian adaptive design on one simulated trial
- [`run_fixed()`](https://adrianwurm.github.io/adaptsurv/reference/run_fixed.md)
  : Run the fixed design on one simulated trial
- [`simulate_trial()`](https://adrianwurm.github.io/adaptsurv/reference/simulate_trial.md)
  : Simulate latent data for a two-arm survival trial
